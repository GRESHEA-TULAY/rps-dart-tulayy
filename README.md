## Description

This is a two-player Rock, Paper, Scissors game written in Dart.
Players enter their names and moves using the keyboard.
The program validates moves, determines the winner, tracks scores,
and allows players to play multiple rounds.

## How to Run

1. Install the Dart SDK.
2. Open the project folder in a terminal.
3. Run the command:

   dart rock_paper_scissors.dart
